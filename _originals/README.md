# Originals

Full-size source images for the case studies, exactly as exported from the tool that made them (Figma, Snagit, Mural, a camera, and so on).

**Never edit a file in this folder.** Make a resized copy and put the copy in `assets/images/projects/<project>/`. If a web copy ever looks wrong, redo it from the original here.

This folder is not published. Jekyll skips any folder that starts with an underscore, and `_config.yml` lists it under `exclude`.

Keep file names in step with the project they belong to, for example `_originals/teal/snagit-capture.webp`.
